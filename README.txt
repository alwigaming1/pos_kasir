=== PANDUAN INSTALASI APLIKASI KASIR (CafePOS v2.0) ===

A. PERSYARATAN SISTEM
1. XAMPP (Versi PHP 7.4 atau 8.x)
2. Browser (Chrome / Edge)
3. Koneksi Printer Thermal (Opsional)

B. CARA INSTALL
1. Copy folder 'kasir' ke dalam folder 'htdocs' di XAMPP.
2. Buka XAMPP Control Panel, nyalakan Apache & MySQL.
3. Buka browser, ketik: localhost/phpmyadmin
4. Buat database baru dengan nama: db_kasir
5. Klik tab "Import", pilih file database (jika ada file .sql) atau copy kode SQL dari developer.
6. Buka aplikasi di: localhost/kasir
